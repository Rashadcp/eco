# Ennerty Solar — EcoHarmony Enterprises

> Premium, award-winning solar energy platform for Kerala homes, commercial properties, and sustainable infrastructure. Powered by EcoHarmony Enterprises Pvt. Ltd.

---

## 🌟 Key Features

- **Interactive Solar System Architecture**: Live animated celestial solar core, orbital radiation waves, and precision photovoltaic generation simulation.
- **Hardware & Products Showcase**: Certified Tier-1 brand matrix (Tata Power Solar, Adani Solar, Waaree Energies, Premier Energies, Emmvee, V-Guard, and Havells) with official vector badges.
- **Interactive Metric & Yield Switcher**: Real-world generation metrics, CO₂ offset telemetry, and investment yield calculations.
- **Responsive Testimonials**: Award-winning editorial layout with photo spotlight and client reviews.
- **Full Mobile & Desktop Optimization**: Ultra-responsive layout with custom glassmorphism, buttery smooth Framer Motion micro-interactions, and accessible typography.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Vanilla CSS
- **Motion**: Framer Motion
- **Icons**: Lucide React
- **Canvas**: HTML5 Canvas with high-DPI scaling

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/winshinebiz-bot/eco-harmony.git

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
